## Project Description

This project is a responsive animated portfolio page built using HTML and CSS.
It demonstrates modern CSS techniques such as transitions, transforms, animations, CSS Grid, Flexbox, and CSS variables.

## Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* CSS Animations (@keyframes)
* CSS Transitions
* CSS Transform
* CSS Variables

## Features

* Responsive navigation bar using Flexbox
* Animated hero section using keyframes
* Interactive buttons with hover transitions
* Portfolio section built with CSS Grid
* Card hover effects using transform and transition
* CSS variables for easy theming
* Responsive design for mobile devices

## How to Run the Project

1. Download or clone the project folder.
2. Make sure `index.html` and `portfolio.css` are in the same directory.
3. Open `index.html` in any web browser.
4. The page will load with full styles and animations automatically.
